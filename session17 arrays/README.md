# جلسه ۱۷ — آرایه‌ها (Arrays)

در این جلسه با ساخت آرایه، دسترسی به عناصر و متدهای اضافه/حذف آشنا می‌شویم.

## هدف جلسه

- تعریف آرایه و خواندن عنصر با ایندکس
- تغییر و افزودن عنصر با ایندکس
- متدهای `push`، `pop`، `unshift`، `shift`
- تمرین جمع و میانگین اعداد واردشده در آرایه


## چه چیزی یاد گرفتیم؟

### ساخت و دسترسی

```js
let fruits = ['apple', 'banana', 'cherry', 'date', 'elderberry'];
console.log(fruits[0]); // apple
```

### تغییر و افزودن با ایندکس

```js
fruits[2] = 'pineapple';
fruits[5] = 'grape';
```

### متدهای ابتدا و انتها

| متد | کار |
|------|-----|
| `push` | افزودن به انتها |
| `pop` | حذف از انتها (و برگرداندن همان عنصر) |
| `unshift` | افزودن به ابتدا |
| `shift` | حذف از ابتدا |

## کارهایی که انجام دادیم

1. یک آرایه‌ی میوه ساختیم و عناصرش را چاپ کردیم
2. عنصر را تغییر دادیم و با ایندکس جدید افزودیم
3. `push` / `pop` / `unshift` / `shift` را تست کردیم
4. تمرینی برای جمع‌آوری اعداد در آرایه نوشتیم

## تمرین‌ها

### `exercise1.js`

- تا وقتی کاربر عدد معتبر وارد می‌کند، عدد را با `push` در آرایه بگذار
- با ورودی نامعتبر از حلقه خارج شو
- جمع و میانگین اعداد را با `alert` نشان بده

## چطور تست کنیم؟

فایل‌ها را در HTML وصل کنید. برای تمرین، چند عدد وارد کنید و بعد یک ورودی خالی/نامعتبر بدهید تا نتیجه را ببینید.

## جمع‌بندی

آرایه لیستی مرتب از مقادیر است. ایندکس از `0` شروع می‌شود. در جلسه‌ی بعد با اشیاء (`object`) داده را ساخت‌یافته‌تر نگه می‌داریم.
