# جلسه ۱۴ — متدهای Math

در این جلسه با شیء `Math` و متدهای ریاضی پرکاربرد آشنا می‌شویم و یک کپچای ساده می‌سازیم.

## هدف جلسه

- آشنایی با `Math.pow`، `Math.sqrt`، `Math.abs`
- پیدا کردن کمینه/بیشینه با `Math.min` و `Math.max`
- گرد کردن با `Math.floor`، `Math.round`، `Math.ceil`
- تولید عدد تصادفی با `Math.random`

## چه چیزی یاد گرفتیم؟

```js
let num = 10.4;
```

| متد | کاربرد |
|------|--------|
| `Math.pow(num, 2)` | توان |
| `Math.sqrt(num)` | جذر |
| `Math.abs(num)` | قدر مطلق |
| `Math.min(...)` / `Math.max(...)` | کوچک‌ترین / بزرگ‌ترین |
| `Math.floor(num)` | گرد به پایین |
| `Math.round(num)` | گرد معمولی |
| `Math.ceil(num)` | گرد به بالا |
| `Math.random()` | عدد تصادفی بین ۰ و ۱ |

عدد تصادفی صحیح بین ۰ تا ۹۹:

```js
Math.floor(Math.random() * 100)
```

## کارهایی که انجام دادیم

1. متدهای اصلی `Math` را روی یک عدد تست کردیم
2. عدد تصادفی تولید کردیم
3. یک تمرین کپچا نوشتیم

## تمرین‌ها

### کپچا (`exercise.js`)

```js
const capcha = Math.floor(Math.random() * 1000000);
const userCapcha = +prompt(`Enter the capcha: ${capcha}`);
```

- یک عدد تصادفی نشان داده می‌شود
- کاربر همان عدد را وارد می‌کند
- در صورت برابر بودن → کپچا درست است

## چطور تست کنیم؟

`script.js` را برای دیدن خروجی متدها در Console اجرا کنید و `exercise.js` را برای تست کپچا.
