# جلسه ۱۰ — عملگر شرطی سه‌تایی (Ternary)

در این جلسه با عملگر Ternary آشنا می‌شویم؛ راه کوتاه برای نوشتن شرط‌های ساده به‌جای `if` / `else`.

## هدف جلسه

- یادگیری سینتکس `شرط ? مقداراگرصحیح : مقداراگرباطل`
- استفاده از Ternary برای کنترل دسترسی بر اساس سن
- درک اینکه Ternary یک عبارت (expression) است و مقدار برمی‌گرداند

## ساختار پروژه

```
session10 Ternary Condition/
├── script.js
└── README.md
```

> در این پوشه فعلاً فقط فایل JS وجود دارد. برای اجرا می‌توانید آن را در یک HTML ساده با تگ `<script>` وصل کنید یا مستقیم در Console مرورگر / محیط Node تست کنید.

## چه چیزی یاد گرفتیم؟

### سینتکس Ternary

```js
شرط ? اگر_درست : اگر_غلط
```

معادل کوتاه‌شده‌ی:

```js
if (شرط) {
    // اگر_درست
} else {
    // اگر_غلط
}
```

### مثال جلسه

```js
let userAge = 18;
let hasAcess = userAge >= 18 ? alert("You have access") : alert("You don't have access");
```

- اگر `userAge >= 18` باشد → پیام دسترسی نمایش داده می‌شود
- در غیر این صورت → پیام عدم دسترسی

> نکته: اینجا خود `alert` به‌عنوان شاخه‌ی Ternary اجرا می‌شود. در حالت تمیزتر معمولاً فقط مقدار برمی‌گردانیم و بعد جداگانه نمایش می‌دهیم:

```js
let message = userAge >= 18 ? "You have access" : "You don't have access";
alert(message);
```

## کارهایی که انجام دادیم

1. سن کاربر را در متغیر گذاشتیم
2. با Ternary دسترسی را چک کردیم
3. پیام مناسب را با `alert` نشان دادیم

## تمرین‌ها

تمرین جدا در پوشه نیست؛ تمرین اصلی بازنویسی یک `if` / `else` ساده با Ternary است. می‌توانید سن‌های مختلف را امتحان کنید یا مثال‌های جلسه ۸ (مثل زوج/فرد) را با Ternary بنویسید.

## چطور تست کنیم؟

یک فایل HTML بسازید و اسکریپت را وصل کنید، یا موقتاً کد را در Console مرورگر اجرا کنید و مقدار `userAge` را عوض کنید.

## جمع‌بندی

| روش | مناسب برای |
|------|------------|
| `if` / `else` | منطق چندخطی و پیچیده |
| Ternary | انتساب مقدار یا انتخاب کوتاه بین دو حالت |

تا اینجا پایه‌ی متغیرها، انواع داده، ورودی کاربر، عملگرها و شرط‌ها را پوشش دادیم. در جلسات بعدی سراغ عملگرهای منطقی و توابع می‌رویم.
