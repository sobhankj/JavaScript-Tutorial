# جلسه ۲ — متغیرها (Variables)

در این جلسه با تعریف متغیر در JavaScript و ذخیره‌ی داده در حافظه آشنا می‌شویم.

## هدف جلسه

- آشنایی با `const` و `let`
- ذخیره‌ی رشته (string) و عدد (number)
- چاپ مقدار متغیرها در Console با `console.log`

## ساختار پروژه

```
session2 basicVar/
├── index.html
├── scripts/
│   └── script.js
└── README.md
```

## چه چیزی یاد گرفتیم؟

### تعریف متغیر با `const` و `let`

```js
const name = 'sobhan kooshki jahromi'
let age = 20
```

- `const`: برای مقادیری که بعداً عوض نمی‌شوند (مثل نام)
- `let`: برای مقادیری که ممکن است تغییر کنند (مثل سن)

### اتصال رشته‌ها (Concatenation)

با عملگر `+` می‌توان متن و متغیر را کنار هم گذاشت و در Console چاپ کرد:

```js
console.log("my name is " + name + " and my age is " + age);
```

## کارهایی که انجام دادیم

1. یک متغیر برای نام با `const` ساختیم
2. یک متغیر برای سن با `let` ساختیم
3. پیام معرفی خودمان را در Console نمایش دادیم

## تمرین‌ها

در این جلسه تمرین جداگانه‌ای تعریف نشده؛ کار اصلی همان تعریف متغیر و چاپ خروجی در `script.js` است.

## چطور تست کنیم؟

1. فایل `index.html` را در مرورگر باز کنید
2. DevTools را باز کنید (`F12`)
3. در تب **Console** پیام معرفی را ببینید

## جمع‌بندی

| مفهوم | توضیح |
|--------|--------|
| `const` | ثابت؛ قابل تغییر نیست |
| `let` | متغیر؛ قابل تغییر است |
| `console.log` | نمایش خروجی در Console |

در جلسه‌ی بعد با انواع داده و `typeof` آشنا می‌شویم.
