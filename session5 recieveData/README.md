# جلسه ۵ — دریافت داده از کاربر

در این جلسه با روش‌های دریافت ورودی از کاربر در مرورگر آشنا می‌شویم: `prompt`، `confirm` و نمایش پیام با `alert`.

## هدف جلسه

- گرفتن متن با `prompt`
- گرفتن تأیید بله/خیر با `confirm`
- نمایش پیام با `alert`
- تبدیل ورودی عددی با `+prompt`
- استفاده از Template String با بک‌تیک (`` ` ``)

## ساختار پروژه

```
session5 recieveData/

```

## چه چیزی یاد گرفتیم؟

### `prompt` — دریافت متن

```js
let name = prompt("Enter your name", "Sobhan Kooshki");
```

آرگومان دوم مقدار پیش‌فرض داخل کادر است.

### تبدیل مستقیم به عدد

```js
let age = +prompt("Enter your age", 22);
```

چون خروجی `prompt` همیشه رشته است، با `+` آن را به عدد تبدیل می‌کنیم.

### `confirm` — سؤال بله/خیر

```js
let isStudent = confirm("Are you a student?");
```

نتیجه `true` یا `false` است.

### `alert` و Template String

```js
alert(`Hello ${name}, you are ${age} years old and you are ${isStudent ? "a student" : "not a student"}`);
```

داخل بک‌تیک می‌توان با `${...}` مقدار متغیر را داخل متن گذاشت. اینجا از شرط کوتاه (ternary) هم برای متن دانشجو بودن استفاده شده است.

## کارهایی که انجام دادیم

1. نام کاربر را با `prompt` گرفتیم
2. سن را گرفتیم و به عدد تبدیل کردیم
3. وضعیت دانشجو بودن را با `confirm` پرسیدیم
4. پیام نهایی را با `alert` نشان دادیم

## تمرین‌ها

تمرین جدا در پوشه نیست؛ کل جلسه یک تمرین عملی دریافت و نمایش داده است.

## چطور تست کنیم؟

1. `index.html` را در مرورگر باز کنید
2. به کادرهای `prompt` و `confirm` پاسخ دهید
3. پیام نهایی را در `alert` ببینید

## جمع‌بندی

| متد | کاربرد | خروجی |
|------|--------|--------|
| `prompt` | دریافت متن | `string` (یا `null`) |
| `confirm` | تأیید بله/خیر | `boolean` |
| `alert` | نمایش پیام | ندارد |

از این جلسه به بعد، ورودی کاربر در بسیاری از مثال‌ها و تمرین‌ها استفاده می‌شود.
