# جلسه ۶ — عملگرهای حسابی (Arithmetic Operators)

در این جلسه با عملگرهای ریاضی در JavaScript کار می‌کنیم و یک تمرین کاربردی برای محاسبه قیمت بعد از تخفیف انجام می‌دهیم.

## هدف جلسه

- آشنایی با عملگرهای `+`، `-`، `*`، `/`، `%`، `**`
- گرفتن دو عدد از کاربر و محاسبه نتایج
- تمرین محاسبه قیمت با تخفیف

## ساختار پروژه

```
session6 arithmatic Op/
├── index.html
├── scripts/
│   ├── script.js
│   └── exercise.js
└── README.md
```

## چه چیزی یاد گرفتیم؟

### عملگرهای حسابی

| عملگر | معنی | مثال |
|--------|------|------|
| `+` | جمع | `a + b` |
| `-` | تفریق | `a - b` |
| `*` | ضرب | `a * b` |
| `/` | تقسیم | `a / b` |
| `%` | باقی‌مانده | `a % b` |
| `**` | توان | `a ** b` |

در `script.js` دو عدد از کاربر گرفته می‌شود و همه‌ی این عملیات در Console چاپ می‌شود:

```js
let a = +prompt("Enter the first number", 0);
let b = +prompt("Enter the second number", 0);
```

## کارهایی که انجام دادیم

1. دو عدد از کاربر گرفتیم
2. جمع، تفریق، ضرب، تقسیم، باقی‌مانده و توان را محاسبه کردیم
3. نتایج را با Template String در Console نشان دادیم

## تمرین‌ها

### تمرین: محاسبه قیمت بعد از تخفیف (`exercise.js`)

- قیمت کالا و درصد تخفیف را از کاربر بگیر
- قیمت نهایی را محاسبه کن:

```js
let discountPrice = price - (price * discount / 100);
```

- نتیجه را با `alert` نمایش بده

> برای اجرای تمرین، اسکریپت `exercise.js` را در `index.html` وصل کنید (به‌جای یا در کنار `script.js`).

## چطور تست کنیم؟

1. `index.html` را باز کنید
2. دو عدد وارد کنید
3. نتایج را در Console ببینید
4. برای تمرین تخفیف، فایل `exercise.js` را اجرا کنید

## جمع‌بندی

عملگرهای حسابی پایه‌ی محاسبات در برنامه‌نویسی هستند. در جلسه‌ی بعد مقایسه‌ی مقادیر با عملگرهای مقایسه‌ای را یاد می‌گیریم.
