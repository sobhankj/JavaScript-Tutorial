# جلسه ۱۶ — حلقه `while`

در این جلسه با `while` آشنا می‌شویم؛ حلقه‌ای که تا وقتی شرط برقرار باشد ادامه پیدا می‌کند.

## هدف جلسه

- ساختار `while (شرط) { ... }`
- افزایش دستی شمارنده داخل حلقه
- حلقه‌ی بی‌نهایت کنترل‌شده با `break`
- بازنویسی برخی تمرین‌های `for` با `while`

## چه چیزی یاد گرفتیم؟

### ساختار پایه

```js
let i = 0;
while (i < 10) {
    console.log(i);
    i++;
}
```

برخلاف `for`، مقدار اولیه و افزایش شمارنده را خودمان جدا می‌نویسیم.

### خروج با `break`

```js
while (true) {
    let num = +prompt('Enter a number');
    if (num === 0) {
        break;
    }
    sum += num;
}
```

## کارهایی که انجام دادیم

1. شمارش ۰ تا ۹ با `while`
2. تمرین‌های شمارش ارقام، جمع ارقام، اعداد زوج در بازه، و جمع تا ورود صفر

## تمرین‌ها

| فایل | موضوع |
|------|--------|
| `exercise1.js` | تعداد ارقام یک عدد |
| `exercise2.js` | جمع ارقام یک عدد |
| `exercise3.js` | چاپ اعداد زوج بین دو عدد (با جابه‌جایی اگر شروع > پایان باشد) |
| `exercise4.js` | جمع اعداد تا وقتی کاربر `0` وارد کند |

## چطور تست کنیم؟

در `index.html` فایل exercise موردنظر را وصل کنید و ورودی‌های مختلف را امتحان کنید.

## جمع‌بندی

| حلقه | مناسب برای |
|------|------------|
| `for` | تعداد تکرار مشخص |
| `while` | ادامه تا برقرار بودن یک شرط |

در جلسه‌ی بعد سراغ آرایه‌ها می‌رویم.
