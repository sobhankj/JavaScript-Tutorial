# جلسه ۱۵ — حلقه `for`

در این جلسه با حلقه‌ی `for` برای تکرار کارها آشنا می‌شویم و چند تمرین عددی و لیستی انجام می‌دهیم.

## هدف جلسه

- ساختار `for (شروع; شرط; گام)`
- پیمایش رشته و آرایه با ایندکس
- جمع، میانگین و شمارش با حلقه

## ساختار پروژه

```
session15 for/
├── index.html
├── script.js
├── exercise.js
├── exercise2.js
├── exercise3.js
├── exercise4.js
├── exercise5.js
└── README.md
```

## چه چیزی یاد گرفتیم؟

### ساختار پایه

```js
for (let i = 0; i < name.length; i++) {
    console.log(name[i]);
}
```

در `script.js` کاراکترهای یک نام را یکی‌یکی چاپ کردیم.

## کارهایی که انجام دادیم

1. حروف یک رشته را با `for` پیمایش کردیم
2. چند تمرین با اعداد زوج/فرد، قیمت محصولات، میانگین و ارقام نوشتیم

## تمرین‌ها

| فایل | موضوع |
|------|--------|
| `exercise.js` | چاپ اعداد زوج ۰ تا ۱۰۰ و اعداد فرد ۹۹ تا ۱ |
| `exercise2.js` | گرفتن قیمت چند محصول از کاربر و جمع کل |
| `exercise3.js` | گرفتن ۵ عدد و محاسبه میانگین |
| `exercise4.js` | شمارش تعداد ارقام یک عدد با تقسیم بر ۱۰ |
| `exercise5.js` | جمع ارقام یک عدد (پیمایش رشته‌ی عدد) |

## چطور تست کنیم؟

در `index.html` مسیر اسکریپت را به فایل موردنظر تغییر دهید و صفحه را در مرورگر باز کنید.

## جمع‌بندی

`for` وقتی تعداد تکرار مشخص است خیلی مناسب است. در جلسه‌ی بعد حلقه‌ی `while` را می‌بینیم که بیشتر با شرط ادامه کار می‌کند.
