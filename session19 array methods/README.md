# جلسه ۱۹ — متدهای آرایه (Array Methods)

در این جلسه متدهای پرکاربرد آرایه را روی لیست کاربران و محصولات تمرین می‌کنیم و چند مینی‌پروژه می‌سازیم.

## هدف جلسه

- پیمایش با `forEach`
- بررسی شرط با `some` و `every`
- پیدا کردن عنصر/ایندکس با `find` و `findIndex`
- فیلتر و تبدیل با `filter` و `map`
- ترکیب این متدها در پروژه‌های کوچک (سبد خرید، تودولیست، آزمون و ...)

## چه چیزی یاد گرفتیم؟ (`script.js`)

روی آرایه‌ای از کاربران این متدها را با هر دو شکل arrow function و function معمولی نوشتیم:

| متد | کاربرد |
|------|--------|
| `forEach` | اجرای کد برای هر عنصر |
| `some` | آیا حداقل یک عنصر شرط را دارد؟ |
| `every` | آیا همه عناصر شرط را دارند؟ |
| `find` | پیدا کردن اولین عنصر مطابق شرط |
| `findIndex` | ایندکس همان عنصر |
| `filter` | ساخت آرایه‌ی جدید از عناصر مطابق شرط |
| `map` | ساخت آرایه‌ی جدید با تبدیل هر عنصر |

## کارهایی که انجام دادیم

1. متدهای بالا را روی لیست کاربران تست کردیم
2. تمرین‌های سبد خرید، بزرگسال بودن، بازیابی رمز، مدیریت محصولات و فیلتر URL نوشتیم
3. چند مینی‌اپ ساختیم: ماشین‌حساب، تودولیست، کپچا، پالیندروم، آزمون و تخصیص تسک

## تمرین‌ها و پروژه‌ها

| فایل | موضوع |
|------|--------|
| `exercise1.js` | سبد خرید: چک موجودی با `some` و جمع قیمت با `forEach` |
| `exercise2.js` | بررسی بزرگسال بودن همه کاربران با `every` |
| `exercise3.js` | پیدا کردن کاربر با `find` و نمایش رمز |
| `exercise4.js` | حذف/افزودن محصول با `findIndex`، `splice`، `push` و `map` |
| `exercise5.js` | فیلتر URLها با `filter` و `includes` |
| `exercise6.js` | جمع قیمت محصولات با `forEach` / `map` |
| `calculator.js` | ماشین‌حساب ساده با `switch` |
| `todolist.js` | تودولیست کامل (افزودن، حذف، نمایش، تکمیل) |
| `capcha.js` | ساخت کپچای تصادفی از عدد و حرف |
| `palindrome.js` | تشخیص پالیندروم با `split` / `reverse` / `join` |
| `exam.js` | آزمون چندسؤالی و محاسبه امتیاز با `forEach` |
| `taskManagement.js` | اختصاص تسک به کارمند با `findIndex` |

> در `index.html` فعلاً `todolist.js` وصل است؛ برای تست بقیه، `src` را عوض کنید.

## چطور تست کنیم؟

1. `index.html` را باز کنید
2. مسیر اسکریپت را به فایل موردنظر تغییر دهید
3. با `prompt`ها تعامل کنید و خروجی را در `alert` یا Console ببینید

## جمع‌بندی

متدهای آرایه کد را کوتاه‌تر و خواناتر از حلقه‌های دستی می‌کنند. در جلسه‌ی بعد با تایمرها (`setTimeout` / `setInterval`) کار ناهمزمان ساده را شروع می‌کنیم.
